# ストア公開チェックリスト（#63）

App Store / Google Play 申請前に整理・作成が必要な項目のチェックリストです。
実際の文章・画像はマーケティング担当と合わせて別途作成してください。

## 共通

- [ ] アプリ名（仮称: 「あとでやること」／正式名称の確定）
- [ ] キャッチコピー: 「スマホ契約後のお金と予定を、忘れない。」
- [ ] アプリアイコン（1024x1024など各サイズ）
- [ ] スクリーンショット（ホーム画面・契約登録・カレンダー・プレミアム画面など）
- [ ] 説明文（日本語。将来的に多言語対応する場合は英語も）
- [ ] プライバシーポリシーURL
  - 個人情報の収集は最小限（契約書・画像・動画・音声は保存しない旨を明記）
  - Googleカレンダー連携時のスコープ・取り扱いを明記（プレミアムのみ）
- [ ] 利用規約URL
  - サブスクリプション（月額298円/年額2,980円、買い切りなし、7日間無料体験）の説明
  - 自動更新・解約方法（各ストアの設定画面から）の説明
- [ ] サポート用連絡先（メールアドレス等）

## iOS (App Store Connect)

- [ ] Bundle ID: `com.atodeyaru.app`
- [ ] 年齢区分（4+想定）
- [ ] プライバシー申告（App Privacy）
  - 収集する可能性のあるデータ: 連絡先情報は収集しない、購入情報（Apple管理）
  - Googleカレンダー連携（プレミアム）を使う場合のみ、外部サービス連携の申告
- [ ] App内課金商品: `premium_monthly`（月額298円）, `premium_yearly`（年額2,980円）
  - Subscription Group を1つ作成し、両プランを同一グループに設定
  - 7日間無料トライアルをStoreKit側の「導入オファー」として設定
- [ ] StoreKit Configuration（開発用）でのテスト

## Android (Google Play Console)

- [ ] applicationId: `com.atodeyaru.app`
- [ ] データセーフティフォーム
  - 収集データ: 購入情報（Google Play管理）、Googleカレンダー連携時のみカレンダーアクセス
  - 契約書・画像・動画・音声は収集しない旨を明記
- [ ] コンテンツのレーティング
- [ ] Google Play Billing商品: `premium_monthly`（月額298円）, `premium_yearly`（年額2,980円）
  - 無料体験（7日間）を商品の「導入価格/無料トライアル」として設定
- [ ] 対象APIレベル（`compileSdk`/`targetSdk` を最新に追従）

## 価格について

価格（月額298円・年額2,980円）はアプリのコードには固定していません。
実際の価格・表示通貨は各ストアの商品設定に従うため、ローカライズ後の
表示価格が異なる場合があります（`SubscriptionService` はストアから
`ProductDetails` を取得して表示する設計です）。
